【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：器械名 / 型号 / 产品名 / 公司名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是型号 / 代号 / 没信息量的 teaser（如 "uMI 780"、"Small is a feature"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "uMI 780" + 来源 "联影医疗新闻" → "联影 uMI 780 PET/MR 发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如"某类影像设备"）兜底，绝不凭"行业常识"编一个具体型号 / 注册证号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品、技术或新数据，就改写成"获批 / 发布 / 推出 / 上市 / 召回"。只有原标题明确宣布了获批、发布、推出、上市或召回，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、型号名。
   例：原标题 "How a new stent lowers restenosis" → "某新型支架如何降低再狭窄"，不能写成 "某公司发布新型支架"。
   例：原标题 "How to choose the right imaging modality" + 来源和正文明确是联影医疗 → "联影医疗影像设备如何选型"，不能只写成缺主体的 "如何选择影像设备"。
