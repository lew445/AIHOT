【医疗器械领域翻译规则 — 本平台 100% 是医疗器械行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非器械歧义，**一律按医疗器械含义翻译**：
   - CE = 欧盟 CE 认证（不是“消费电子”）；MDR / IVDR = 欧盟医疗器械法规 / 体外诊断医疗器械法规
   - 510(k) / De Novo / PMA = 美国 FDA 的三条上市前路径（保留英文，不译）
   - 介入 = 介入治疗 / 介入器械（不译“干预”“调解”）
   - 影像 = 医学影像（不是泛指的图像处理）
   - IVD = 体外诊断；SaMD = 医疗器械软件（保留英文）
   - 植入物 = 植入人体的器械（不译“移植”）
   - 支架 = 血管或腔内支架（不译“支撑”）
   - 瓣膜 = 心脏瓣膜（不译“阀门”）
   - 导管 = 医用导管（不译“管道”）
   - 召回 = 器械召回（不译“记忆”“唤起”）
   - 集采 = 集中带量采购；带量采购不写成“批量购买”
   - 注册证 = NMPA 医疗器械注册证
   - 适应证 = indication（不引申成“适应症”以外的含义）
