# 技术方向（field）主题细分重构方案

## 概要

把 `industry/topics.json` 中「技术方向」（`field`）分组下的主题做一次细化与重组：

- **移除**「高值耗材」（太粗糙）。
- **拆分**「神经与脑机接口」为「神经介入」与「脑机接口」两个主题。
- **收窄**「心血管介入」为「冠脉介入」。
- **新增**「结构心脏病」「电生理」「外周介入」，并参考微创医疗（MicroPort）业务板块额外新增「心律管理（CRM）」。

由于主题归类依赖文章标签与 `TOPIC_TAGS` 白名单，且「理解」步骤提示词里有一份主题字面清单，因此需同步修改 3 个文件：`industry/topics.json`、`industry/taxonomy.ts`、`industry/prompts/content-understanding.md`。

## 现状分析

- **主题定义来源**：`industry/topics.json` 是主题的源数据；`packages/backend/src/publication/topics.ts` 的 `seedTopics()` 按 `slug` upsert 到 `topics` 表（见 [topics.ts](file:///workspace/packages/backend/src/publication/topics.ts#L32-L47)）。注意：**只 upsert、不删除**，移除/改名的 slug 会在数据库留下旧行。
- **主题匹配规则**：`topicMatchTags()` 决定文章归属——`field`/`genre` 主题按其 `tags` 与文章标签重叠匹配（见 [topics.ts](file:///workspace/packages/backend/src/publication/topics.ts#L57-L63)）。因此主题的 `tags` 必须出现在 `TOPIC_TAGS` 白名单里，否则文章永远拿不到该标签，主题会是空的。
- **标签白名单/归一化**：`packages/backend/src/editorial/vocabulary.ts` 用 `ALLOWED_TAGS = CATEGORY_TAGS ∪ TOPIC_TAGS ∪ ENTITY_TAGS` 过滤模型输出，并用 `TAG_SYNONYMS` 做近义词归一（见 [vocabulary.ts](file:///workspace/packages/backend/src/editorial/vocabulary.ts#L7-L25)）。
- **提示词**：`structure.md` 的主题清单是 `{{topicTags}}` 动态注入（见 [analyze.ts](file:///workspace/packages/backend/src/editorial/analyze.ts#L143-L151)），会随 `TOPIC_TAGS` 自动同步；而 `content-understanding.md`（「理解」步骤）里是**字面写死的**主题清单（见 [content-understanding.md](file:///workspace/industry/prompts/content-understanding.md#L40)），必须手工同步。
- **当前 field 主题**：手术机器人、医学影像、体外诊断、心血管介入、骨科、神经与脑机接口、眼科、内窥镜、高值耗材、康复与家用器械、生物材料与制造（见 [topics.json](file:///workspace/industry/topics.json#L139-L225)）。
- **相关引用点**：`related` 数组用 slug 互相引用，涉及 `cardio`、`consumables`、`neuro-bci`（如 `clinical`、`procurement`、`funding`、`microport`、`abbott`、`boston-scientific`、`medtronic`）。
- 无测试或脚本校验 topics.json 与词表的一致性（已确认 `tests/` 无相关断言），故一致性需人工/一次性脚本核对。

## 假设与决策

- **高值耗材**：从 `TOPIC_TAGS` 与 `topics.json` 中整体移除（不仅是 field 主题），并删除 `耗材 → 高值耗材` 同义词；`低值耗材` 保留（用户仅点名高值耗材）。
- **cardio 的 slug 保持不变**，只改显示名/标签/定义，以避免 URL 变更和历史数据孤立。
- **neuro-bci 拆为两个新 slug**（`neuro-intervention`、`bci`）；旧 slug 行需运维清理（见下）。
- **额外方向取「心律管理（CRM）」**（用户已确认）；`手术机器人/骨科/眼科/内窥镜` 等与 MicroPort 板块重合的方向保持现状不动。
- **数据库清理（既有部署）**：`seedTopics()` 只 upsert，不移除旧 slug。已有环境的 DB 会残留 `consumables`、`neuro-bci` 行，上线后需手动执行 `DELETE FROM topics WHERE slug IN ('consumables','neuro-bci');`（或重置种子数据）。新环境无此问题。
- 修改 `taxonomy.ts` 的 `TOPIC_TAGS` 后，`structure.md` 的 `{{topicTags}}` 自动同步，无需改动该文件。
